# pathtest

A test repository. Every directory name in `contrib/` is deliberately wrong:
the folder names describe serious-sounding systems, and the code inside does
something completely different and trivial. Each package's README says what it
actually does.

This repository exists to check whether a tool reads file contents or only file
paths. Nothing here is real and no person named below exists.

## Packages

| Path | What the name suggests | What the code actually does |
|---|---|---|
| `contrib/pell-harrow/fraud_detection` | fraud detection | plays tic-tac-toe |
| `contrib/pell-harrow/patient_triage` | patient triage | scales a banana bread recipe |
| `contrib/noor-bastien/credit_scoring` | credit scoring | rolls dice |
| `contrib/noor-bastien/wildfire_prediction` | wildfire prediction | converts integers to Roman numerals |
| `contrib/okada-vance/flight_path_optimizer` | flight path optimisation | sorts a Christmas card list |
| `contrib/okada-vance/payroll_processor` | payroll processing | prints ASCII cats |
| `contrib/mirembe-fox/inventory_forecasting` | inventory forecasting | generates a weather haiku |
| `contrib/mirembe-fox/string_utils` | string utilities | string utilities (this one matches) |
